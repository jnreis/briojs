Bind Directive

The bind directive is used to bind a prop/expression to a DOM attribute. The attribute value is updated when any of its reactive data change, if any.

Full syntax

b-bind-[attr-name]="[prop or expression]"

Example: b-bind-name="name"

Shorthand syntax

The shorthand syntax can be used when the prop name is the same as the attribute name.

bind-[attr-name]

Example: bind-name

Initial attribute value

Get the initial value of the DOM attribute (if any) by using the $initial magic property.

This is useful when you need to concatenate the prop value with the initial value of the attribute.

Example: class="bg-slate-700" bind-class="$initial + ' text-white'"

Notes

  • If the value is true, the attribute value is set to an empty string.
  • If the value evaluates to false, the attribute is removed. E.g. false, null, undefined, 0, empty string, etc.
  • The attributes "src", "value", "checked", and "selected" are always set. And they are set to their actual value, even if the value is true or false. And their DOM properties are also updated.
    • The "src" property normalizes the path and ensures the new resource is loaded.
    • The properties "value", "checked", and "selected" reflect the current state of the element they are set on.
  • The attribute name can not be a Brio.js directive.
