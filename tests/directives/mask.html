b-mask Directive Manual Tests

Tests input masking, phone patterns, and currency formatting helpers.

1. Phone Number Mask: (###) ###-####

2. Date Mask: ##/##/####

Enter 12/25/1987. Put the caret just after the second slash and press Delete: expect 12/25/987 with the caret after 5, not at the end. Also try Backspace on a slash and replacing a selection.

3. Optional Money Formatter: brio.moneyMask()

Model: ${$data.moneyVal}. Type 123456: expect 1,234.56.

Delete or insert a digit in the middle, or delete a separator: the caret stays next to the edited digits. Repeat with a selected range and the custom separators below.

4. Reactive Formatter Options

Model: ${$data.euroVal}. Type 123456: expect 1.234,56. This input also checks b-model before b-mask.

5. Configurable Money Formatters

Type 1234567: expect 1 234,567.

Type 1234: expect 1,234 (no fractional digits).

6. Unicode Pattern Tokens and Escaping

* accepts any code point (including emoji), A a Unicode letter or decimal digit, a a Unicode letter, and # a Unicode decimal digit. 9 is literal. Backslash escapes a token. Combining marks are separate code points.

7. Custom Function (No Registry or Plugin Required)

The expression returns a synchronous formatter. Simple formatters return a string; advanced formatters return a value and UTF-16 selection offsets.
