Directive .options Manual Tests

Options are read once at hydration. Attribute order does not matter, and option values override dot modifiers. The .options attribute uses the directive's base name, without other modifiers.

Unknown keys, non-object values, orphan options, and options on unsupported directives throw errors. For example, b-on-click.options="{ delay: 100 }" is invalid; use debounce or throttle.
