3. Device pixels and document target

Device-pixel measurements are physical pixels, not CSS pixels. Browser support is required: unsupported requested measurements report an error rather than silently returning content size.

Device-pixel content box

Resize the browser window to exercise .document. You can also set document: true in b-on-resize.options. Default observations use the element and content-box. All observers disconnect on unmount.
