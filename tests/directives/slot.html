Scoped slots: b-slot and $slot

The outlet exposes values with b-slot. Supplied markup reads $slot while $data, $props, $for, and refs keep the supplying parent's context. Names are optional and literal.

Reverse preserves each row and input. Replacing an item updates $slot without recreating its markup. Each repeated input gets a unique ID through b-id. Parent handlers own edits.

Fallback: no content supplied

Unfilled outlets render their fallback in component scope ($for.item and $props), not the supplying parent's $slot.

Contract

b-slot accepts a non-null, non-array object on a slot outlet in a component template. Modifiers and dynamic slot names are not supported. Values update reactively; removal disposes the output. Supplied objects are not deep-frozen: treat them as inputs.
