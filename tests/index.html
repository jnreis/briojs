01 / Put the pieces together

Complete apps

Mock backends and simulated teammates keep these demos self-contained. Some apps save data in your browser; please do not enter sensitive information.

counter

Venue occupancy counter: state, events, keyboard shortcuts, keyed log, ARIA meter

temperature-converter

Derived state, accessor two-way bindings, validation, persistence

conditional-form

Conference registration: conditional branches, validation, dynamic attributes, async submit

todomvc

TodoMVC: keyed lists, CRUD, inline editing, hash filters, computed counts, persistence

7guis

7GUIs: constraints, timer, CRUD, undo/redo circle drawer, spreadsheet with cycle detection

large-table

1,000/10,000 keyed rows: create, partial update, select, swap, remove, timed per operation

dashboard

Sales analytics: async loading/abort/retry, 10k-order derived KPIs, SVG charts, live feed, 100+ nested components

conduit

RealWorld blog: routing with guards and paged URLs, token auth, mock REST API, optimistic favorites/follows, shared cache

kanban

Trello-like board: drag-and-drop (mouse and keyboard), nested card state, optimistic saves with rollback, live teammate sync, offline catch-up

collab-editor

Collaborative docs: operational transform, live teammate cursors, offline edits that merge on reconnect, exactly-once saves, version history and restore
