HTTP Client (http) Manual Tests

Tests http.get, http.post, JSON request bodies, and automatic response parsing.

GET/DELETE accept nested query objects or URLSearchParams. POST/PUT/PATCH accept JSON data or native Fetch bodies. Automatic parsing recognizes JSON and +json; 204/205 and empty JSON return undefined. Explicit parsers retain native behavior.

Non-OK responses throw brio.HttpError with status and an unread response. Network and parsing errors remain native. Inspect the collapsible page setup for loading/error handling.

2. Nested queries and explicit query keys

Brackets preserve nested objects and arrays. Null becomes an empty value, undefined disappears, and Dates become ISO strings. Existing query entries remain. Explicit URLSearchParams can repeat plain keys instead.


    


    

        
3. JSON, form, and binary request bodies

        
POST/PUT/PATCH use JSON for plain data and preserve supplied headers.
            Native bodies pass through; Fetch creates multipart boundaries and keeps
            typed-array slice offsets. The echo includes the bytes received by the server.

        
        
        
        
        
        

    


    

        
4. Automatic parsing and empty responses

        
JSON and +json media types parse automatically. JSON-looking text stays text.
            Automatic 204/205 and zero-length JSON return undefined; empty text remains "".
            Malformed nonempty JSON rejects rather than silently returning text.

        
        
        
        

    


    

        
5. Explicit native response parsers

        
Override a misleading content-type, read JSON as text, or request Blob,
            ArrayBuffer, and FormData. Explicit JSON on an empty body throws a native
            SyntaxError, even for 204.

        
        
        

    


    

        
6. HTTP errors, invalid input, and cancellation

        
HttpError exposes status and an unread response. Parsing, serialization,
            and cancellation failures are not HttpError. The slow request takes two
            seconds unless cancelled; app disposal also aborts it.
